Intelligent Agent Application

A Q-Learning agent trained to navigate a 7×7 maze from start (S) to goal (G), learning the optimal path through trial and error across 600 episodes.

🧩 Problem Context

The agent is a robot navigating a maze. Placed at the top-left cell (S), it must reach the bottom-right cell (G) while avoiding walls, in the fewest steps possible.

The agent has no prior knowledge of the maze layout. It discovers the optimal route purely through interaction: trying actions, receiving rewards or penalties, and updating its internal Q-table. Over episodes, its behavior transitions from random exploration to precise navigation.

🔍 Interpretation of Results
What the Agent Learned

Starting with completely random behavior (ε = 1.0), the agent explored the maze blindly, hitting walls and accumulating penalties. Over episodes, the Q-table accumulated experience: cells near the goal gained high Q-values, propagating backwards through the Bellman equation. By episode ~300, the agent consistently found the goal; by episode 600, its path was near-optimal.

How Decisions Improved

Early episodes show high variance in reward (many wall collisions, no goal reached). As epsilon decayed, the agent shifted from exploration to exploitation of the best-known path. The "steps per episode" chart shows this clearly: hundreds of steps early on, converging to the optimal path length as training matured.

Advantages of Q-Learning
  • No prior model of the environment needed (model-free).
  • Guaranteed convergence to the optimal policy in discrete, finite MDPs.
  • Simple to implement; interpretable Q-table for small state spaces.
  • Off-policy: learns from any experience, including random exploration.
Limitations
  • Does not scale to large or continuous state spaces (curse of dimensionality).
  • Requires many episodes to converge in complex environments.
  • Static maze: does not generalize to environments that change over time.
  • No function approximation; each state is treated independently.
Possible Improvements
  • Replace Q-table with a neural network → Deep Q-Network (DQN).
  • Add experience replay and target networks for stability.
  • Use Double Q-Learning to reduce overestimation bias.
  • Implement a dynamic maze that changes between episodes.
