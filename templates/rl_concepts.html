Reinforcement Learning – Basic Concepts

What is Reinforcement Learning?

Reinforcement Learning (RL) is a branch of machine learning where an agent learns to make decisions by interacting with an environment. Unlike supervised learning, no labeled dataset is required. Instead, the agent receives rewards or penalties based on the actions it takes, and gradually learns which actions lead to the best long-term outcome.

The core idea is simple: the agent tries different actions, observes the consequences, and updates its behavior to maximize cumulative reward over time — very similar to how humans and animals learn through trial and error.

Intelligent Agent

An intelligent agent is the decision-making entity in a Reinforcement Learning system. It perceives the current state of the environment, selects an action based on a policy, and receives feedback in the form of a reward. Over many iterations, the agent refines its decision-making strategy to achieve its objective more effectively.

Examples of intelligent agents include: a robot navigating a warehouse, a program playing chess, a self-driving car choosing a route, or a recommendation system selecting content for a user.

Environment

The environment is everything outside the agent — the world the agent interacts with. It receives the agent's actions and responds by transitioning to a new state and providing a reward signal. The environment can be:

  • Deterministic: The same action always leads to the same result.
  • Stochastic: Actions can lead to different outcomes with some probability.
  • Fully observable: The agent sees the complete state of the environment.
  • Partially observable: The agent only sees part of the environment.
States

A state is a snapshot of the environment at a given moment. It contains all the information the agent needs to decide what action to take next. For example, in a maze, a state could be the agent's current position (row, column). States form the foundation of the agent's perception of the world.

Actions

Actions are the choices available to the agent in each state. The set of all possible actions is called the action space. Actions can be discrete (e.g., move up, down, left, right) or continuous (e.g., steering angle of a vehicle). The agent must learn which action to take in each state to maximize its reward over time.

Rewards

A reward is a numerical signal the environment sends back to the agent after each action. It indicates how good or bad the action was in the current state. The agent's ultimate goal is to maximize the total accumulated reward (called cumulative reward or return) over a full episode or over time.

  • Positive reward: Encourages the agent to repeat the action.
  • Negative reward (penalty): Discourages the agent from taking that action.
  • Zero reward: Neutral — the action neither helped nor hurt.
Policies

A policy (π) is the agent's strategy — a mapping from states to actions. It defines what the agent does in every possible situation. Policies can be:

  • Deterministic: π(s) → a — always picks the same action for a given state.
  • Stochastic: π(a|s) — assigns a probability to each action in a given state.

The learning process in RL consists of finding the optimal policy π* that maximizes cumulative reward across all states.

Exploration vs. Exploitation

One of the central challenges in Reinforcement Learning is the exploration–exploitation tradeoff:

  • Exploitation: The agent uses its current knowledge to select the action it believes is best — maximizing known reward.
  • Exploration: The agent tries new, uncertain actions to discover potentially better strategies it hasn't encountered yet.

A common approach to balance both is the ε-greedy strategy: with probability ε (epsilon), the agent explores randomly; with probability 1−ε, it exploits the best known action. As training progresses, ε is typically reduced so the agent gradually focuses more on exploitation.

The Learning Process

The RL learning cycle follows a continuous loop:

  1. The agent observes the current state (s).
  2. It selects an action (a) based on its policy.
  3. The environment transitions to a new state (s').
  4. The agent receives a reward (r).
  5. The agent updates its knowledge (e.g., Q-table or neural network weights).
  6. The cycle repeats until a terminal state or episode limit is reached.

Over many episodes (complete runs from start to terminal state), the agent accumulates experience and progressively improves its policy.

Key Algorithms
Algorithm Type Description
Q-Learning Model-free, off-policy Learns a Q-table mapping (state, action) → expected reward. Simple and effective for discrete spaces.
SARSA Model-free, on-policy Similar to Q-Learning but updates based on the action actually taken, making it more conservative.
Deep Q-Network (DQN) Model-free, off-policy Uses a neural network to approximate Q-values, enabling RL in high-dimensional or continuous state spaces.
Policy Gradient (REINFORCE) Model-free, on-policy Directly optimizes the policy by gradient ascent on expected cumulative reward.
Real-World Applications
  • Gaming: AlphaGo (Go), OpenAI Five (Dota 2), agents that beat human champions.
  • Robotics: Teaching robotic arms to grasp objects, bipedal locomotion.
  • Autonomous vehicles: Path planning, lane keeping, collision avoidance.
  • Finance: Algorithmic trading strategies that adapt to market conditions.
  • Healthcare: Personalized treatment policies and drug dosage optimization.
  • Supply chain: Inventory management and delivery route optimization.
  • Natural language: Fine-tuning language models with human feedback (RLHF).
